Work with us

MindWork.com is built by a small, remote group of contributors. Work is project-based and paid per project, funded by sponsors and supporters.

Roles we take applications for

Cognitive science writer
Write and update guides. You read the primary studies, cite them, and say plainly when the evidence is weak.
Puzzle and test designer
Design new browser tests grounded in research tasks, with scoring that is fair on any device.
Front-end developer
Build tools in plain HTML, CSS and JavaScript that load fast and work with a keyboard and a screen reader.
Illustrator or motion designer
Explain how a model or a memory process works in one clear picture.
Community and contests coordinator
Run the monthly challenge, verify entries and keep the hall of fame honest.
Partnerships and sponsorship
Find sponsors whose products fit the audience, and keep the labelling clear.

Projects open as funding allows, so there may be a wait between applying and hearing about a project. We keep applications on file for twelve months.
